# Déclaration d'utilisation de l'intelligence artificielle

## Contexte

Dans le cadre de ce projet, nous avons utilisé ChatGPT comme outil d'assistance afin de nous accompagner dans certaines phases de développement et de documentation.

L'IA a été utilisée comme un support pédagogique pour mieux comprendre certains concepts techniques, améliorer la qualité de notre documentation et relire certaines parties du projet.

---

# Utilisations réalisées

Au cours du développement, nous avons notamment utilisé ChatGPT pour :

- mieux comprendre certains mécanismes liés au Web Scraping ;
- obtenir des explications sur le fonctionnement des erreurs HTTP et du retry exponentiel ;
- réfléchir à des solutions pour rendre le parseur plus robuste ;
- relire et améliorer la structure de notre documentation ;
- préparer la soutenance en générant des questions techniques et des pistes de réponse.

---

# Exemples de questions posées

Voici quelques exemples de demandes formulées pendant le projet :

- *Comment gérer correctement les erreurs HTTP temporaires (429, 500, 502, 503) ?*
- *Pourquoi privilégier des sélecteurs sémantiques plutôt que des classes CSS ?*
- *Comment organiser un projet de Web Scraping en plusieurs modules ?*
- *Peux-tu relire notre README et proposer une version plus pédagogique ?*
- *Quels types de questions pourraient être posés lors d'une soutenance sur ce projet ?*

---

# Notre démarche

Les réponses proposées par l'IA n'ont jamais été intégrées directement sans vérification.

Chaque proposition a été :

- analysée ;
- adaptée au contexte du projet ;
- testée localement ;
- validée ou modifiée en fonction des résultats obtenus.

Nous avons également vérifié les sélecteurs HTML, les URL, les contraintes imposées par le sujet ainsi que les résultats produits par le scraper.

# Engagement

L'intelligence artificielle n'a pas été utilisée pour contourner des mécanismes de protection, accéder à des données non publiques ou produire un travail sans compréhension.

Elle a uniquement servi d'outil d'accompagnement afin de faciliter notre apprentissage et d'améliorer la qualité du projet, tout en respectant les consignes du module.
